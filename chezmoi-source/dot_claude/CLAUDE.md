## PR review comments
When writing PR review comments, follow [Conventional Comments](https://conventionalcomments.org/): `<label> [decoration]: <subject>`. Labels: `praise`, `nitpick`, `suggestion`, `issue`, `todo`, `question`, `thought`, `chore`, `note`. Decorations: `(non-blocking)`, `(blocking)`, `(if-minor)`.

## Commit messages
Write commit messages as a single-line subject only — no body — unless I explicitly ask for a longer message.
